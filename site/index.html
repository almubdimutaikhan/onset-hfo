Onset Review is open-source software for intracranial EEG. It detects high-frequency oscillations and interictal discharges, measures where seizures start, and shows the interval behind every rate and the signal behind every event, so that a reader can check each one.

Built for reading, not just running

A rate measured over a minute is a small count. Onset Review treats it that way: every number carries its uncertainty, every event keeps its evidence, and the reader has the last word.

The answer first, with its interval

One sentence states which channel leads, its rate with a 95% Poisson interval, and how many other channels cannot be told apart from it. Channels whose intervals overlap are shown together as a tied set, never as a ranking the data cannot support.

Judge events one at a time

Review mode gives one event the whole screen: the wideband signal, the band-passed signal and a time–frequency map on one time axis. A real, D not real, U unsure, and the next event follows. Verdicts are saved under the reader's name and go into the report.

Detection you can check

Four detectors (RMS, line length, Hilbert envelope, short-time energy) share every stage except the feature they threshold, so a disagreement points at the feature. Each event is tested against its own 1/f spectral background, which rejects the filter ringing that sharp transients produce. Rejected events are kept, with the reason.

Signal settings start from measured defaults, with a Noisy recording preset and a two-second preview of the filters.

Where seizures start

For each marked seizure, the Epileptogenicity Index scores how strongly and how early each channel's fast activity rose. A case keeps one patient's recordings, marks, segments and results together, with an audit log.

Open data, one click away

Open your own recordings (EDF, BrainVision, FIF, BIDS-iEEG and the other formats MNE reads) or search OpenNeuro and download only the window you need. Scalp EEG and MEG open too, marked as unvalidated.

An assistant that cannot make numbers up

Optional, and local: an open-weight model runs on your machine through Ollama, and no data leave it. Every number it states must come from a tool result, every citation must resolve to real evidence, and questions about treatment or diagnosis are refused before the model runs.

Reports without recommendations

Rates with intervals, detector disagreements, data quality and the reader's verdicts. The report has no field for a recommendation.

Python underneath

An optional analysis mode adds an editor, a console that shares the open recording, and ready-made scripts for every analysis.

Batch and compare

Run the same settings over many recordings into one table, or compare two analyses side by side.

Tested

1,587 automated tests run offline, on Python 3.10 and 3.12, with the desktop window built headless in CI.

A correction, kept on the record

A first version of the outcome analysis used the first 60 s of each recording and reached AUC 0.82, p = 0.007. On whole recordings it is 0.71, p = 0.12, and five disjoint minutes give p from 0.007 to 0.613. The software therefore analyses whole recordings by default and shows tied sets instead of one channel.

How it works

The analysis writes a result store; the window, the report and the assistant only read it. Every rate resolves to the events behind it, and every event to the signal it was measured on.

ReadBIDS-iEEG, EDF, BrainVision, FIF and more; OpenNeuro by byte range
Preparehigh-pass, mains notch, bipolar montage; bad channels and segments set aside
Detectripples, fast ripples, interictal discharges, Epileptogenicity Index
Validateeach event against its own spectral background
Rank honestlyexact Poisson intervals and tied sets
Reviewreader verdicts, report, optional checked assistant

Built on MNE-Python and its Qt browser, NumPy, SciPy and pandas. MIT licence.

Install

Ubuntu or Pop!_OS

Download onset-hfo-<version>-linux.tar.gz from the latest release, then:

tar xzf onset-hfo-*-linux.tar.gz
cd onset-hfo-*-linux
./install.sh --with-sample --with-assistant
~/.local/bin/onset-review

--with-sample adds one minute of one public recording to start with; --with-assistant installs Ollama and a model suited to the machine. Both are optional.

From source, any platform with Python 3.10+

git clone https://github.com/berdakh/onset-hfo.git
cd onset-hfo/onset-hfo
python -m venv .venv && . .venv/bin/activate
pip install -e ".[review]"
onset-review

The analysis library alone needs only pip install -e . and runs from the command line. Full install guide.

What it must not be used for

  • Clinical decisions. It is not a medical device and has not been validated for clinical use. It issues no diagnosis and no recommendation.
  • Reading a rate as a seizure-onset zone. Physiological ripples occur in healthy tissue; a busy channel may simply be healthy cortex.
  • Overreading the validation. The outcome cohort has 20 patients from one centre; the association has the published direction but is not significant. Agreement with experts is moderate, and the expert markings are themselves a reviewed detector's output.
  • Trusting the assistant's emphasis. Its checks stop invented numbers, not misleading emphasis or omissions. The report is authoritative.
  • Your own data without approval. De-identification, ethics approval and data governance are yours.
